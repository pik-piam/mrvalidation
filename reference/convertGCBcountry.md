# convertGCBcountry

Fill the country-level GCB bookkeeping fluxes to the standard ISO
country list.

## Usage

``` r
convertGCBcountry(x)
```

## Arguments

- x:

  magpie object returned by readGCBcountry

## Value

magpie object on the 249 ISO countries
