# downloadGCBcountry

Download the Obermeier et al. (2024) country-level LULUCF carbon flux
dataset (net and gross fluxes of the GCB bookkeeping models), archived
on Zenodo (8144174).

## Usage

``` r
downloadGCBcountry()
```

## See also

[`downloadSource`](https://rdrr.io/pkg/madrat/man/downloadSource.html)
